## Программа

Программа состоит из объявлений верхнего уровня: `fn`, `struct`, `enum`, `impl`, `const`, `import` и `extern fn`. Выполнение начинается с функции `main`:

```orbitron
fn main() {
    println("Привет!");
}
```

Если `main` возвращает `int`, это значение становится кодом завершения процесса:

```orbitron
fn main() -> int {
    if parse_int(read_line()) < 0 { 1 } else { 0 }
}
```

Объявления можно располагать в любом порядке: функцию разрешено вызывать до её определения. Глобальных изменяемых переменных нет, для общих значений используйте `const`.

## Лексика

**Комментарии**: `// до конца строки` и `/* блочные, могут быть /* вложенными */ */`.

**Идентификаторы** состоят из букв (любых, включая кириллицу), цифр и `_` и не могут начинаться с цифры. Имя `_` можно использовать для неиспользуемой переменной цикла.

**Ключевые слова**: `let var const fn return if else while for in loop break continue match struct impl enum import extern defer true false self as`.

**Целые литералы**: `42`, `1_000_000`, `0xff`, `0o755`, `0b1010`. Символьный литерал `'A'` — это целое число, код символа Unicode (`'A' == 65`, `'я' == 1103`).

**Вещественные литералы**: `3.14`, `2.0`, `1e-9`, `6.02e23`. Точка требует цифр с обеих сторон: `1.` и `.5` не являются литералами.

**Строки**: `"текст"`. Экранирование: `\n \t \r \0 \\ \" \' \{ \} \u{1F680}`.

## Типы

| Тип | Значения | Пример |
|---|---|---|
| `int` | 64-битное целое со знаком | `-7`, `0xff` |
| `float` | 64-битное IEEE 754 | `3.14`, `1e10` |
| `bool` | `true`, `false` | `x > 0` |
| `str` | неизменяемая строка UTF-8 | `"мир"` |
| `[T]` | динамический массив | `[1, 2, 3]` |
| `Name` | структура или перечисление | `Point`, `Color` |
| `fn(A, B) -> R` | функция | `fn(int) -> int` |

Функция без `-> тип` ничего не возвращает. Тип `void` явно не пишется.

**Неявных преобразований нет.** `1 + 2.0` — ошибка компиляции. Для приведения используйте `as`:

| Из | В | Правило |
|---|---|---|
| `int` | `float` | точное значение или ближайшее представимое |
| `float` | `int` | дробная часть отбрасывается; вне диапазона — насыщение до `int` min/max; `NaN` → `0` |
| `bool` | `int` | `true` → `1`, `false` → `0` |
| перечисление | `int` | номер варианта, начиная с 0 |

Строки получаются интерполяцией (`"{x}"`), числа из строк — функциями `parse_int` и `parse_float`.

## Переменные и константы

```orbitron
let name = "Orbitron";   // неизменяемая привязка
var count = 0;           // изменяемая переменная
count += 1;

let ratio: float = 0.5;  // явный тип
var items: [str] = [];   // для пустого массива тип обязателен
```

Переменная обязана получить значение при объявлении. Тип выводится из инициализатора.

Повторное объявление с тем же именем скрывает прежнее (shadowing), в том числе в той же области видимости:

```orbitron
let input = "42";
let input = parse_int(input);   // теперь input: int
```

**Константы** объявляются на верхнем уровне и вычисляются при компиляции. В их значении допустимы литералы, другие константы, арифметика, сравнения и `as`:

```orbitron
const WIDTH: int = 80;
const HALF: int = WIDTH / 2;
const TITLE: str = "Отчёт";
const EPS: float = 1e-9;
```

## Операторы

От высшего приоритета к низшему:

| Приоритет | Операторы | Ассоциативность |
|---|---|---|
| 1 | `x.поле` `x.метод()` `f()` `a[i]` | слева |
| 2 | `**` | справа |
| 3 | унарные `-` `!` `~` | — |
| 4 | `as` | слева |
| 5 | `*` `/` `%` | слева |
| 6 | `+` `-` | слева |
| 7 | `<<` `>>` | слева |
| 8 | `&` | слева |
| 9 | `^` | слева |
| 10 | `\|` | слева |
| 11 | `==` `!=` `<` `<=` `>` `>=` | слева |
| 12 | `&&` | слева |
| 13 | `\|\|` | слева |
| 14 | `\|>` | слева |

Особенности:

- `-x ** 2` означает `-(x ** 2)`, а `2 ** 3 ** 2` — `2 ** 9`;
- битовые операции связывают сильнее сравнений, поэтому `x & 1 == 0` означает `(x & 1) == 0` (в C наоборот);
- `/` и `%` для `int` округляют к нулю (`-7 / 2 == -3`, `-7 % 3 == -1`); деление на ноль вызывает ошибку выполнения;
- переполнение `int` происходит с заворачиванием (`9223372036854775807 + 1` даёт минимальное значение);
- `**` для `int` требует неотрицательной степени;
- сдвиги берут величину сдвига по модулю 64, `>>` арифметический;
- `&&` и `||` вычисляют правую часть только при необходимости;
- `==` и `!=` работают с `int`, `float`, `bool`, `str` и перечислениями; `<`, `<=`, `>`, `>=` — с `int`, `float` и `str` (строки сравниваются побайтово). Структуры, массивы и функции сравнивать нельзя;
- `+` склеивает строки.

Составное присваивание: `+= -= *= /= %= &= |= ^= <<= >>=`. Присваивание — это инструкция, а не выражение.

## Строки

Внутри строкового литерала `{выражение}` подставляет значение любого выражения типа `int`, `float`, `bool`, `str` или перечисления:

```orbitron
let n = 3;
println("у меня {n} {if n == 1 { "яблоко" } else { "яблока" }}, всего {n * 10} грамм");
println("фигурные скобки: \{это не интерполяция\}");
```

Интерполированная строка — обычное значение типа `str`, её можно сохранять и передавать.

**Числа выводятся одинаково на обоих бэкендах**:

- `float` печатается кратчайшей записью, которая однозначно восстанавливает число: `0.1 + 0.2` → `0.30000000000000004`;
- при `1e-5 <= |x| < 1e16` используется обычная запись, всегда с дробной частью: `3.0`, `0.001`;
- в остальных случаях используется научная запись: `1.0e16`, `1.5e-7`;
- особые значения: `inf`, `-inf`, `NaN`, `-0.0`.

Строки хранятся в UTF-8. **Длины и индексы считаются в байтах**: `"мир".len() == 6`. Методы строк:

| Метод | Результат |
|---|---|
| `s.len()` | длина в байтах |
| `s.byte(i)` | байт с индексом `i` (0–255), с проверкой границ |
| `s.slice(a, b)` | подстрока из байтов `[a, b)`; границы должны попадать на начала символов |
| `s.contains(t)` | содержит ли `s` подстроку `t` |
| `s.find(t)` | индекс первого вхождения в байтах или `-1` |

Строки нельзя индексировать через `s[i]`. Другие функции для строк есть в модуле [`std/strings`](stdlib.md#stdstrings).

## Блоки и выражения

Блок `{ ... }` содержит инструкции и, необязательно, завершающее выражение без `;`. Значение этого выражения становится значением блока:

```orbitron
let area = {
    let w = 3;
    let h = 4;
    w * h          // без точки с запятой: значение блока
};
```

Инструкции заканчиваются `;`. Исключение — `if`, `match`, циклы и блоки, записанные отдельной инструкцией: после них `;` не нужна.

`return`, `break`, `continue`, `panic(...)` и `exit(...)` никогда не возвращают управление. Их тип `never` совместим с любым типом, поэтому такое выражение можно поставить в любую ветку:

```orbitron
let n = if s == "" { return 0; } else { parse_int(s) };
```

## Условия: if

Условие не берётся в скобки и обязано иметь тип `bool`. Фигурные скобки обязательны.

```orbitron
if x > 0 {
    println("положительное");
} else if x < 0 {
    println("отрицательное");
} else {
    println("ноль");
}
```

`if` с веткой `else` является выражением:

```orbitron
let abs = if x >= 0 { x } else { -x };
```

Тернарного оператора нет, его роль выполняет `if`.

## Сопоставление: match

```orbitron
let text = match code {
    200 => "OK",
    301 | 302 => "перенаправление",
    400..500 => "ошибка клиента",   // 400 <= code < 500
    500..=599 => "ошибка сервера",  // включительно
    _ => "неизвестно",
};
```

Сопоставлять можно значения типов `int`, `str`, `bool` и перечислений. Образцы:

| Образец | Пример |
|---|---|
| целое число | `0`, `-1` |
| диапазон | `1..10`, `1..=9` |
| строка | `"да"` |
| `true` / `false` | `true` |
| вариант перечисления | `Color::Red` |
| любое значение | `_` |
| несколько образцов | `1 \| 2 \| 3` |

Ветки проверяются по порядку. Тело ветки — выражение, за ним ставится запятая; если тело является блоком `{ ... }`, запятая не нужна.

Если `match` возвращает значение, компилятор проверяет, что ветки покрывают все случаи: все варианты перечисления, оба значения `bool` или есть ветка `_`. Используемый как инструкция `match` может покрывать не всё.

## Циклы

```orbitron
for i in 0..10 { }          // 0, 1, ..., 9
for i in 1..=10 { }         // 1, ..., 10
for x in [3, 1, 4] { }      // элементы массива
while cond { }
loop { }                    // бесконечный цикл, выход через break или return
```

- границы диапазона вычисляются один раз до начала цикла; включительный диапазон корректно доходит до максимального `int`;
- переменная цикла неизменяема;
- `for x in массив` перечитывает длину на каждой итерации, поэтому элементы, добавленные в цикле, тоже будут обработаны;
- `break` выходит из ближайшего цикла, `continue` переходит к его следующей итерации;
- `loop` без `break` имеет тип `never`, поэтому функция, которая заканчивается таким циклом, может не возвращать значение после него.

## Функции

```orbitron
fn add(a: int, b: int) -> int {
    a + b              // последнее выражение — результат
}

fn greet(name: str) {
    if name == "" {
        return;        // ранний выход
    }
    println("Привет, {name}!");
}
```

Параметры неизменяемы. Типы параметров и результата указываются всегда. Функция с результатом обязана вернуть значение на каждом пути.

Рекурсия разрешена. Перегрузки и параметров по умолчанию нет.

## Функции как значения

Имя функции — это значение типа `fn(...) -> ...`:

```orbitron
fn twice(f: fn(int) -> int, x: int) -> int { f(f(x)) }
fn inc(x: int) -> int { x + 1 }

let g = inc;
println(twice(g, 5));                              // 7
println(twice(fn(x: int) -> int { x * 10 }, 5));   // 500
```

**Анонимная функция** записывается как `fn(параметры) -> тип { тело }`. Она не захватывает локальные переменные окружающей функции; значения передаются через параметры. Константы и другие функции доступны.

**Конвейер** `x |> f(a, b)` означает `f(x, a, b)`, а `x |> f` означает `f(x)`:

```orbitron
let r = "  текст " |> trim |> to_upper;
let s = range(0, 10) |> filter(is_even) |> sum;
```

Методы типов также можно получить как значения: `Point::new`.

## Массивы

```orbitron
var xs = [1, 2, 3];          // [int]
let zeros = [0; 100];        // 100 нулей
var names: [str] = [];       // пустой массив: тип обязателен

xs.push(4);
let last = xs.pop();         // 4
xs[0] = 10;
println(xs.len());           // 3
```

- обращение `a[i]` проверяет границы, выход за них приводит к ошибке выполнения;
- `pop()` у пустого массива приводит к ошибке выполнения;
- **массивы передаются по ссылке**: функция может изменить переданный массив, а `let b = a` не копирует данные;
- `[v; n]` кладёт в каждую ячейку одно и то же значение. Для структур и массивов это одна общая ссылка, поэтому `[[0; 3]; 2]` содержит две ссылки на один и тот же внутренний массив. Независимые строки создавайте в цикле.

## Структуры

```orbitron
struct Point {
    x: float,
    y: float,
}

impl Point {
    // функция типа: без self, вызывается как Point::new(...)
    fn new(x: float, y: float) -> Point { Point { x, y } }

    // метод: первый параметр self
    fn dist(self, o: Point) -> float {
        let dx = self.x - o.x;
        let dy = self.y - o.y;
        sqrt(dx * dx + dy * dy)
    }

    fn move_by(self, dx: float) {
        self.x += dx;
    }
}

let a = Point::new(0.0, 0.0);
let b = Point { x: 3.0, y: 4.0 };
println(a.dist(b));       // 5.0
```

- в литерале структуры задаются все поля в любом порядке; запись `Point { x, y }` означает `Point { x: x, y: y }`;
- инициализаторы полей вычисляются в порядке объявления полей в структуре;
- **структуры имеют ссылочную семантику**: значение структуры — ссылка на объект. Методы и функции могут менять поля, `let` запрещает только переприсваивание самой переменной;
- поле может хранить функцию; вызов `obj.callback(x)` вызовет её, если у типа нет метода `callback`;
- `null` нет, поэтому каждая структура всегда полностью инициализирована.

## Перечисления

```orbitron
enum Color { Red, Green, Blue }

impl Color {
    fn hex(self) -> str {
        match self {
            Color::Red => "#f00",
            Color::Green => "#0f0",
            Color::Blue => "#00f",
        }
    }
}

let c = Color::Green;
println("{c} = {c.hex()}");   // Green = #0f0
println(c as int);            // 1
```

Варианты не несут данных. Перечисления сравниваются через `==`, выводятся по имени варианта, приводятся к `int` номером варианта и поддерживают методы через `impl`.

## defer

`defer` откладывает выполнение выражения до выхода из **текущего блока**: обычного, через `return`, `break` или `continue`. Несколько `defer` выполняются в обратном порядке.

```orbitron
fn work() -> int {
    println("начало");
    defer println("конец");      // выполнится последним
    defer println("уборка");     // выполнится перед «конец»
    42                           // значение вычисляется до выполнения defer
}
```

Внутри `defer` нельзя использовать `return`, а также `break` и `continue`, выходящие за его пределы. `exit()`, `panic()` и ошибки выполнения завершают программу без выполнения отложенных выражений.

## Модули

```orbitron
import "geometry";       // файл geometry.ot рядом с текущим файлом
import "util/text";      // util/text.ot относительно текущего файла
import "std/math";       // модуль стандартной библиотеки
```

Импорт подключает все объявления модуля в общее пространство имён программы. Каждый файл подключается один раз, циклические импорты допустимы. Одинаковые имена функций, типов или констант в разных модулях считаются ошибкой.

## Внешние функции

LLVM-бэкенд умеет вызывать функции из библиотеки C:

```orbitron
extern fn puts(s: str) -> int;
extern fn getpid() -> int;

fn main() {
    puts("из libc");
}
```

Допустимые типы параметров и результата: `int` (`int64_t`), `float` (`double`), `bool`, `str` (`const char*`, строка с нулём в конце). Программы с `extern fn` нельзя собрать JVM-бэкендом.

## Встроенные функции

Доступны без импорта:

| Функция | Описание |
|---|---|
| `print(x)`, `println(x)`, `println()` | вывод `int`, `float`, `bool`, `str` или перечисления (`println` добавляет перевод строки) |
| `eprintln(x)` | вывод в stderr |
| `read_line() -> str` | строка из stdin без `\n`; `""` в конце ввода |
| `parse_int(s) -> int`, `parse_float(s) -> float` | разбор числа; пробелы по краям допустимы, при неверном вводе возникает ошибка выполнения |
| `chr(code) -> str` | строка из одного символа с кодом Unicode `code` |
| `abs(x)`, `min(a, b)`, `max(a, b)` | для `int` и `float` |
| `sqrt`, `sin`, `cos`, `tan`, `exp`, `ln`, `floor`, `ceil`, `round` | `float -> float`; `round` округляет половины от нуля |
| `atan2(y, x)` | `float` |
| `clock() -> float` | монотонное время в секундах, для замеров |
| `assert(cond)`, `assert(cond, "сообщение")` | проверка условия |
| `panic(msg)` | аварийное завершение с сообщением (код 101) |
| `exit(code)` | немедленное завершение с кодом |

Собственная функция программы с тем же именем перекрывает встроенную.

## Ошибки выполнения

Выход за границы массива или строки, деление на ноль, `pop()` из пустого массива, неверный ввод в `parse_int` и подобные ошибки завершают программу с кодом **101**. В stderr выводится сообщение с местом в исходнике:

```
ошибка выполнения: индекс 5 вне границ массива длины 3 (main.ot:9:15)
```

Перед завершением буфер stdout сбрасывается, поэтому весь вывод до ошибки сохраняется.

## Модель памяти и ограничения

- строки, массивы и структуры живут в куче. LLVM-бэкенд не освобождает память до завершения программы (сборщика мусора нет), в JVM работает сборщик мусора Java. Для типичных консольных программ это не проблема, но долгие циклы, порождающие много строк, расходуют память в нативной сборке;
- обобщённых типов, `null`/`Option`, исключений и перечислений с данными пока нет;
- анонимные функции не захватывают окружение;
- математические функции (`sin`, `exp` и т. п.) в редких случаях могут отличаться между бэкендами в последнем знаке.

## Грамматика

```
program    = { item } ;
item       = "import" STRING ";"
           | "const" IDENT [ ":" type ] "=" expr ";"
           | "fn" IDENT "(" [ params ] ")" [ "->" type ] block
           | "extern" "fn" IDENT "(" [ params ] ")" [ "->" type ] ";"
           | "struct" IDENT "{" [ field { "," field } [ "," ] ] "}"
           | "enum" IDENT "{" IDENT { "," IDENT } [ "," ] "}"
           | "impl" IDENT "{" { fn } "}" ;
params     = ( "self" | param ) { "," param } ;
param      = IDENT ":" type ;
field      = IDENT ":" type ;
type       = IDENT | "[" type "]" | "fn" "(" [ type { "," type } ] ")" [ "->" type ] ;

block      = "{" { stmt } [ expr ] "}" ;
stmt       = ( "let" | "var" ) IDENT [ ":" type ] "=" expr ";"
           | "defer" expr ";"
           | place assign_op expr ";"
           | expr ";"
           | block_expr ;
assign_op  = "=" | "+=" | "-=" | "*=" | "/=" | "%=" | "&=" | "|=" | "^=" | "<<=" | ">>=" ;

expr       = binary expressions by the precedence table, "as" type, unary, postfix ;
postfix    = primary { "(" args ")" | "." IDENT [ "(" args ")" ] | "[" expr "]" } ;
primary    = INT | FLOAT | STRING | "true" | "false" | "self"
           | IDENT | IDENT "::" IDENT | IDENT "{" [ init { "," init } ] "}"
           | "(" expr ")" | "[" [ args ] "]" | "[" expr ";" expr "]"
           | "fn" "(" [ params ] ")" [ "->" type ] block
           | block_expr | "break" | "continue" | "return" [ expr ] ;
block_expr = block
           | "if" expr block [ "else" ( block | if_expr ) ]
           | "match" expr "{" { pattern { "|" pattern } "=>" expr [ "," ] } "}"
           | "while" expr block
           | "for" IDENT "in" ( expr ( ".." | "..=" ) expr | expr ) block
           | "loop" block ;
pattern    = "_" | [ "-" ] INT [ ( ".." | "..=" ) [ "-" ] INT ] | STRING | "true" | "false" | IDENT "::" IDENT ;
```

В условиях `if`, `while`, `match` и `for` запись `Имя { ... }` не считается литералом структуры. Если литерал нужен в условии, возьмите его в скобки.
