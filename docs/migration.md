# Переход со старого синтаксиса

Версия 0.2 — это полная переработка языка. В старой версии одна и та же вещь записывалась несколькими способами (`var`/`let`/`mut`/`var mut`, `println`/`println!`, `#const`/`const`, `class`/`struct`), почти все значения фактически были `i64`, а ошибки в программе приводили к падению компилятора. Теперь у каждой конструкции одна запись, есть настоящая система типов и понятные сообщения об ошибках.

## Соответствие конструкций

| Было | Стало |
|---|---|
| `var x = 1;` / `let x = 1;` | `let x = 1;` (неизменяемая) |
| `var mut x = 1;` / `mut x = 1;` | `var x = 1;` (изменяемая) |
| `#const N: i64 = 5;` | `const N: int = 5;` |
| `i64`, `f64` | `int`, `float` |
| `func f()` / `fn f(): i64` | `fn f() -> int` |
| `fn f(x: i64): i64 => x * 2;` | `fn f(x: int) -> int { x * 2 }` |
| `println!(x)` / `println(x)` | `println(x)` |
| `"x = \{x}"` / `$"x = {x}"` | `"x = {x}"` |
| `if (x > 0) { }` | `if x > 0 { }` |
| `unless (c) { }` | `if !c { }` |
| `a > b ? a : b` | `if a > b { a } else { b }` |
| `x ?: y` | нет: `null` больше не существует |
| `repeat 5 { }` | `for _ in 0..5 { }` |
| `do { } while (c);` | `loop { ...; if !c { break; } }` |
| `class Foo { init(...) { } }`, `new Foo(...)` | `struct Foo { }` + `impl Foo { fn new(...) -> Foo { ... } }`, `Foo::new(...)` |
| `public` / `private` / `protected` / `internal` | убраны: всё видно внутри программы |
| `extends`, `trait` | убраны (пока нет) |
| `Color.Red` в выражениях | `Color::Red` |
| `match` с `=> { println!(...); }` и `return 0;` | `match` — выражение: `Color::Red => "красный",` |
| `\|x\| x * 2` | `fn(x: int) -> int { x * 2 }` |
| `var (a, b) = (1, 2);` (кортежи) | убраны: используйте структуру |
| `import "std/math";` / `#import` | `import "std/math";` |
| `extern fn f(...): i64;` | `extern fn f(x: int) -> int;` с типами параметров |
| `go { }`, `chan()`, `async`/`await` | убраны: в старой версии они не давали настоящей параллельности |
| `ptr_write`, `&x`, `*p`, `syscall(...)` | убраны; для низкого уровня используйте `extern fn` |
| `readInt()` | `parse_int(read_line())` или `read_int()` из `std/io` |

## Что стало строже

- **Типы проверяются.** `1 + 2.0`, `if 1 { }`, `let s: str = 5;` теперь ошибки компиляции с подсказкой, как исправить.
- **Условия имеют тип `bool`.** Вместо `while (!t.done())`, где `done()` возвращал 0 или 1, метод должен возвращать `bool`.
- **Неизменяемость соблюдается.** Присваивание переменной, объявленной через `let`, является ошибкой.
- **Функция с результатом должна вернуть значение** на каждом пути.
- **Массивы знают свою длину.** Не нужно передавать длину отдельным параметром: используйте `xs.len()` и `for x in xs`. Выход за границы ловится во время выполнения.
- **Строки являются настоящими значениями** `str`: их можно хранить в полях, массивах, сравнивать и склеивать.
