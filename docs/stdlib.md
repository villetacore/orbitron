# Стандартная библиотека

Модули подключаются через `import "std/имя";`. Они написаны на самом Orbitron, исходники лежат в [`stdlib/`](../stdlib) и работают на обоих бэкендах. Встроенные функции (`println`, `sqrt`, `abs`, `min`, `max` и другие) описаны в [описании языка](language.md#встроенные-функции) и не требуют импорта.

## std/math

| Имя | Описание |
|---|---|
| `PI`, `TAU`, `E` | константы `float` |
| `INT_MAX`, `INT_MIN` | границы `int` |
| `sign(x: int) -> int` | `-1`, `0` или `1` |
| `clamp(x, lo, hi: int) -> int`, `clamp_float(...)` | ограничение отрезком |
| `gcd(a, b) -> int`, `lcm(a, b) -> int` | НОД и НОК |
| `is_prime(n) -> bool` | проверка на простоту |
| `factorial(n) -> int` | факториал |
| `fib(n) -> int` | число Фибоначчи (`fib(0) = 0`) |
| `isqrt(n) -> int` | целочисленный квадратный корень |
| `hypot(x, y) -> float` | длина гипотенузы |
| `to_radians(deg)`, `to_degrees(rad)` | перевод углов |
| `lerp(a, b, t) -> float` | линейная интерполяция |

## std/strings

Длины и индексы считаются в байтах UTF-8.

| Функция | Описание |
|---|---|
| `starts_with(s, prefix)`, `ends_with(s, suffix) -> bool` | проверка начала и конца строки |
| `trim(s) -> str` | убирает пробельные символы по краям |
| `split(s, sep) -> [str]` | делит строку по разделителю |
| `join(parts: [str], sep) -> str` | склеивает части через разделитель |
| `replace(s, from, to) -> str` | заменяет все вхождения |
| `repeat(s, n) -> str` | повторяет строку `n` раз |
| `to_upper(s)`, `to_lower(s)` | меняет регистр латинских букв |
| `pad_left(s, width, fill)`, `pad_right(...)` | дополняет строку до нужной ширины |
| `count(s, sub) -> int` | число вхождений подстроки |
| `is_space(b)`, `is_digit(b)`, `is_alpha(b)` | классы байтов (`s.byte(i)`) |

## std/arrays

Функции для `[int]`, с отдельными вариантами для `[float]` там, где это нужно.

| Функция | Описание |
|---|---|
| `range(lo, hi) -> [int]` | массив `lo..hi` |
| `sum(xs)`, `sum_float(xs)` | сумма |
| `min_of(xs)`, `max_of(xs)` | минимум и максимум (ошибка для пустого массива) |
| `index_of(xs, v) -> int`, `contains(xs, v) -> bool` | поиск |
| `copy(xs) -> [int]` | копия массива |
| `reverse(xs)` | разворот на месте |
| `sort(xs)`, `sort_float(xs)` | сортировка на месте |
| `filter(xs, pred: fn(int) -> bool)` | новый массив из подходящих элементов |
| `map(xs, f: fn(int) -> int)` | новый массив из `f(x)` |
| `fold(xs, init, f: fn(int, int) -> int)` | свёртка |
| `to_str(xs)`, `to_str_float(xs)` | запись вида `"[1, 2, 3]"` |

## std/bits

| Функция | Описание |
|---|---|
| `popcount(x)` | число единичных битов |
| `bit(x, i) -> bool` | значение `i`-го бита |
| `set_bit`, `clear_bit`, `toggle_bit` | изменение `i`-го бита |
| `is_power_of_two(x) -> bool` | является ли число степенью двойки |
| `shr_logical(x, n)` | логический сдвиг вправо |
| `to_binary(x)`, `to_hex(x)` | запись неотрицательного числа в двоичной или шестнадцатеричной системе |

## std/io

| Функция | Описание |
|---|---|
| `input(prompt) -> str` | печатает приглашение и читает строку |
| `read_int() -> int` | читает целое число |
| `read_float() -> float` | читает вещественное число |
